# سامانه فروش لبیک یا مهدی

پروژه Google Apps Script برای مدیریت فروش، سفارش‌ها، پرداخت‌ها و نمایندگان فروش با Google Sheets.

## مرحله فعلی

مرحله سوم پیاده‌سازی انجام شده است: ساختار پایه، دیتابیس Google Sheets و جستجوی محصول با کد در پنل مشتری آماده شده‌اند.

## فایل‌های اصلی

- `appsscript.json`: تنظیمات پروژه Google Apps Script.
- `Main.gs`: نقطه ورود Web App و تابع راه‌اندازی اولیه.
- `Config.gs`: تنظیمات فنی، نام شیت‌ها و ستون‌های تاییدشده.
- `Database.gs`: لایه متمرکز ارتباط با Google Sheets.
- `Router.gs`: مسیریابی ساده صفحات HTML.
- `Response.gs`: ساخت پاسخ استاندارد برای Frontend.
- `Utils.gs`: ابزارهای عمومی مثل تولید UUID و استانداردسازی کد محصول/موبایل.
- `Products.gs`: توابع Backend محصولات و جستجوی محصول با کد.
- فایل‌های HTML/CSS/JS پایه برای پنل مشتری، مدیریت و نماینده.

## راه‌اندازی اولیه

پس از اتصال پروژه به Google Apps Script، تابع `setupProject` را اجرا کنید تا ۹ شیت اصلی و ستون‌های تاییدشده ایجاد یا بررسی شوند. برای smoke test پایه Database Service نیز می‌توانید تابع `testDatabaseService` را اجرا کنید.
